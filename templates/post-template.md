New posts start as a copy of this page. Change `draft: true` → `draft: false` to publish.

Frontmatter fields this site understands:

| Field | What it does |
| ----- | ------------ |
| `title` | Page title and browser tab name |
| `description` | Shown in link previews, search, and page lists |
| `date` | Used for sorting Posts and the RSS feed |
| `tags` | Powers the tag index — use freely |
| `aliases` | Extra names other pages can link to |
| `draft` | `true` keeps the page off the built site entirely |

Conventions:

- Link between pages with `[[wikilinks]]` or normal markdown links — both work.
- Date format is `YYYY-MM-DD`.
- Maturity tags on Thoughts pages: #folio, #quire, #codex.
