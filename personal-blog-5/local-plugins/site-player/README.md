# site-player

Floating ambient music player. Demonstrates a component plugin whose real
work happens in an `afterDOMLoaded` script (see TUTORIAL.md §6).

- Playlist: edit `quartz/static/playlist.json` — an array of
  `{ "title": "...", "src": "/static/music/your-file.mp3", "note": "why it matters" }`
- Demo loops were generated by `node scripts/generate-music.cjs` — replace
  them with real files any time.
- The player keeps playing across page navigation (persistent audio element,
  re-anchored on the `nav` event). Position/track/volume restore from
  localStorage. Double-click the play button to re-open a minimized player.
