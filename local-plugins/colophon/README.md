# colophon

A one-file Quartz plugin that adds a hand-set colophon line to the footer of
every page. This is the reference example for writing your own plugins —
see TUTORIAL.md §9.

Structure:
- `package.json` — the `quartz` field is the manifest Quartz reads
- `dist/components/index.js` — the component (plain JS, preact `h()`)
